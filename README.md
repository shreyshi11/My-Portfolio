## 📌 About The Project

This is my personal developer portfolio designed to provide a professional overview of my technical skills, projects, achievements, education, and extracurricular activities.

The website focuses on a **clean, responsive, and interactive user experience** while presenting my work in a way that is easy for recruiters, developers, and visitors to explore.

## 🚀 Getting Started

To run this project locally:

### 1. Clone the repository

```bash
git clone https://github.com/shreyshi11/My-Portfolio.git
```

### 2. Navigate to the project directory

```bash
cd My-Portfolio
```

### 3. Open the project

You can simply open:

```text
index.html
```

in your preferred web browser.

Alternatively, use the **Live Server** extension in VS Code for a better development experience.
